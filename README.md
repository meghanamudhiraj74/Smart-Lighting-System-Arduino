# Smart Lighting System using Arduino

## Project Overview
This project is a Smart Lighting System developed using Arduino UNO and an LDR sensor. 
The system automatically turns ON an LED in dark conditions and turns it OFF in bright conditions.

## Components Used
- Arduino UNO
- LDR Sensor
- LED
- 220Ω Resistor
- 10kΩ Resistor
- Breadboard
- Jumper Wires

## Working Principle
The LDR sensor detects surrounding light intensity and sends analog values to Arduino. 
Based on the sensor value, Arduino controls the LED automatically.
